## oDash 1.0.0

First public release.

- Traffic per device, per site and per category, live throughput and top services
- Device list with names, fixed IPs, speed limits, blocking, time rules and a 7-day connection timeline
- Network, multi-WAN, Wi-Fi and Wi-Fi uplink management
- Speed, ping and DNS/IP leak tests
- Samba, disk format/mount/safe-remove
- Fan and LED control, schedules, scheduled backups, export/import, in-panel updates
- Five themes (Default is the plain LuCI look)

Install on the router:

```sh
wget -qO- https://raw.githubusercontent.com/fzdamk/oDash/main/install.sh | sh
```
